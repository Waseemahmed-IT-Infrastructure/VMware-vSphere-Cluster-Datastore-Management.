
# VMware vSphere - Cluster and Datastore Management

## Overview

This repository covers cluster, datastore and ESXi host management using VMware vSphere and vCenter.

My work includes checking infrastructure resources, managing virtual machines, reviewing storage capacity and working with vSphere licensing.

## Cluster Management

A cluster is a group of ESXi hosts managed together through vCenter.

Common tasks include:
- Checking ESXi host status
- Reviewing CPU and memory resources
- Checking cluster alerts
- Reviewing VM placement and resource availability

## Datastore Management

Datastores provide storage for virtual machines and their files.

My main tasks include:
- Checking datastore capacity and free space
- Selecting storage when creating virtual machines
- Browsing datastore files
- Uploading ISO files
- Investigating storage alerts

## ESXi Host Management

- Checking host connectivity and health
- Reviewing host resource usage
- Checking virtual machines running on a host
- Reviewing host warnings and alerts

## vSphere Licensing

Licensing is an important part of VMware infrastructure management.

Common tasks include:
- Checking license status
- Reviewing assigned licenses
- Checking license usage and available capacity
- Verifying licensing before infrastructure changes

## Basic Troubleshooting

| Issue | What to Check |
|---|---|
| Host disconnected | Host connectivity and alerts |
| Datastore low on space | Used and available storage |
| VM resource issue | Host CPU, memory and VM settings |
| License warning | Assigned license and entitlement |
| Cluster alert | Host and cluster events |
